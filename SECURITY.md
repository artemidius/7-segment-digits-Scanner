# Security reports

Use [GitHub private vulnerability reporting](https://github.com/artemidius/7-segment-digits-Scanner/security/advisories/new)
for vulnerabilities. Include the affected version, impact, and a minimal reproduction.
Avoid posting private photos, credentials, or exploit details in public issues.

The current alpha is the supported development line. This is a small volunteer
project; no response-time or long-term-support guarantee is offered.

The library processes images locally and loads a model supplied by the host app.
Use trusted model artifacts with verified hashes. This project does not validate
the medical correctness or completeness of a recognized reading.
